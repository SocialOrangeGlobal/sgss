# Sri Guru Singh Sabha | Craigieburn

Welcome to the official web platform for **Sri Guru Singh Sabha, Craigieburn** – a Sikh Gurdwara serving the community in Craigieburn, Victoria, Australia.

## 📖 Project Summary

This project is a modern web application built for the Sri Guru Singh Sabha Gurdwara. It aims to provide the community with up-to-date information on Diwan programs, community news, educational initiatives, and other Gurdwara services. The platform is designed with a responsive, user-friendly interface that embodies the spiritual and communal values of the Sikh community.

## ✨ Features

- **Modern UI/UX**: Built with Tailwind CSS and Framer Motion for a smooth, animated, and responsive user experience.
- **Dynamic Content**: Sections for Diwan Programs, Quick Links, and embedded Video content right on the homepage.
- **Accessible Design**: Utilizing Shadcn UI and Radix UI primitives to ensure high accessibility standards.
- **Form Handling**: Contact and employment inquiries managed seamlessly with React Hook Form and Zod validation.
- **SEO Optimized**: Utilizes Next.js App Router metadata and OpenGraph tags for better search engine visibility.

## 🗺️ Pages & Navigation

The application consists of the following key pages:

- **Home (`/`)**: The main landing page featuring the Hero Slider, Diwan Programs, Quick Links, and a Video Section.
- **About (`/about`)**: Information about the Gurdwara, its history, mission, and the community it serves.
- **Programs (`/programs`)**: Details on daily/weekly Diwan programs, Kirtan, Katha, and special events.
- **News (`/news`)**: Latest updates, community news, and announcements.
- **Religion (`/religion`)**: Information covering Sikhism, its principles, and teachings.
- **School (`/school`)**: Details regarding Punjabi school, Gurbani classes, and educational activities for youth.
- **Employment (`/employment`)**: Opportunities and forms for job openings or volunteer work within the organization.
- **Contact (`/contact`)**: Location details, contact forms, and communication channels to reach the Gurdwara administration.

## 🛠️ Tech Stack

This project is built using industry-standard technologies:

- **Framework**: [Next.js](https://nextjs.org/) (App Router, v15+)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Components**: [Shadcn UI](https://ui.shadcn.com/) (Radix UI + Tailwind)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Forms**: React Hook Form with Zod validation
- **Analytics**: Vercel Analytics

## 🚀 Getting Started

To run this project locally, follow these steps:

### Prerequisites

Make sure you have Node.js (v18+ recommended) installed.

### Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/SocialOrangeGlobal/sgss.git
cd sgss
npm install
# or
pnpm install
```

### Running the Development Server

Start the local development server:

```bash
npm run dev
# or
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application in action.

## 🌍 Deployment

This project is optimized for deployment on [Vercel](https://vercel.com/):

1. Push your code to your GitHub repository (`SocialOrangeGlobal/sgss`).
2. Log in to Vercel and click **Add New Project**.
3. Import the `SocialOrangeGlobal/sgss` repository.
4. Leave the default build settings (Framework: Next.js) and click **Deploy**.

Within a couple of minutes, your application will be live globally!
